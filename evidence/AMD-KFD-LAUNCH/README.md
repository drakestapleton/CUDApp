# Direct KFD launcher CPU evidence

`receipt.json` is generated from the exact source head, gate output and artifacts. `qualification.log` contains commands and observed exits. `results.json` holds the native syscall records and negative controls; `notebook-check.json` holds both-target parsing of the staged objects and the independent reference calculations. All actual GPU, timing, model-serving and Spark-comparison rows are NOT_RUN.

`bundle/cell.py` is the exact staged launch1 cell, with its JSON, executable and code objects. Each object records the commit that supplied its bytes. The correct attention merge was selected by the integrating lane's full digest. No peer branch was merged. `bin/` contains the tested native and x86 executables. Host instruments and their actual versions are in `instruments.json`; they are not production dependencies.

The generic CLI control runs past the ring boundary with repeated packets and checks output bits and cleanup. Suppressing the simulator's completion makes the child exit 75; the observer fails as required. Another control changes the allocation GPU ID and must fail at the ioctl oracle. Instruction-step observation kills an early-valid-header mutant. A changed compiler digest refuses before executing it or creating output, and a changed notebook binary digest refuses before execution. Device absence is exercised through real qemu x86 execution, not a fabricated result.

Investigation evidence is retained separately. The first ELF check used an incorrect manually supplied e_ident word; the recorded Python byte conversion now derives the expected value. The next native trace stopped before allocation: a raw x86 O_DIRECTORY flag was not portable to AArch64. The installed fcntl preprocessing query returned O_DIRECTORY=040000 and O_DIRECT=0200000 on this host. Opening the known topology directory read-only and letting getdnts enforce its directory type removed that architecture-specific flag. `investigation/gate-2` records the failed source/result; `gate-3` records the repaired precursor. They are not the final gate receipt.

The production changes are the assigned launcher directory. External tests are under tests/amd-kfd-launch; root PROVENANCE.md is updated for the new direct-KFD path and named kernel/ROCT references. Existing kernel generators and sibling source trees were not edited. Missing MI300X access in this CPU-only assignment prevents hardware qualification; it is not labelled PASS.
