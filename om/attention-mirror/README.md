# Scoped attention history mirror

This candidate carries the existing 30B GPU-cached history mechanism into 27B attention. Omega owns request admission, bounded allocation reuse and the operation sequence. Existing native transport allocates device-private memory and runs the existing copy and attention kernels. It adds no attention arithmetic, reduction-order change, dependency or persistent-prefix validity assumption.

`plan.om` accepts an exact seven-element request: mode, query heads, K/V heads, capacity in positions, starting position, row count and bytes per K/V plane. Zero means bypass, all-ones means refusal, and another value is the required mirror size. Bounds and geometry are checked before multiplication. The layout constants come from `omega_gpu_decode_attn256_api.h` and `omega_blackwell_codegen_attn256.h`, including the tail slack; they are implementation contracts, not claimed chip limits.

`step.om` directs allocation when capacity is insufficient, PREP, full K/V copy and ATTEND. Each operation must report successful completion before the next action is selected. A failure prevents attention or output publication. One buffer is reused across layers and requests, and released by the existing attention cleanup/session-close path. The CPU never reads or writes it. Original cache contents remain authoritative for decode and saved state.

The new per-call entry has modes 0 (ordinary), 1 (mirror all supported requests) and 2 (provisional threshold at 1024 rows). Mode 2 avoids copying on tiny calls. This threshold needs further performance qualification. No process-global selector or deployed default changes. Existing host, device and recorded calls keep their behavior.

The external measuring prototype preserved every complete-score bit in six short/long cases and the 32,768-token plus short-after-long comparison. The long read measured 108.036 seconds before and 102.269 seconds with cached history, including copy cost. These are single shared-machine observations of the prototype, not qualification of this new production source or server first-token delay. Current source status is BUILDING. Native dispatch, physical parity, full-model serving and controlled timing must be recorded at its own source identity.

Run `make test-attention-mirror-policy test-attention-mirror-dispatch` with the repository's pinned Omega compiler and Bridge. The independent host oracle checks admission and transitions, including malformed inputs and failed completion; source mutations challenge geometry, bounds, short-call bypass, both-plane copy, capacity and ordering. Python is external verification only. The actual native dispatch instrument substitutes fake device transport to inspect the executed sequence and its failure paths without opening a GPU.
